# Agent instructions (DiskPilot fork)
Read ROADMAP.md and docs/AI-CLEANUP.md before edits. Preserve AGPL-3.0-only and upstream attribution. Work in small branches/PRs; no direct pushes to main without owner direction. Keep scanner, headless agent, CLI and existing UI behavior compatible; avoid unrelated refactors. First isolate upstream updater and app identity before distributing builds. No release publishing or signing with upstream credentials. AI is advisory only; MVP read-only. Never run cleanup against real user files in tests, never execute model-generated shell commands, never bypass safety checks or silently permanently delete. Treat filenames and model output as untrusted. Keep secrets and personal paths out of logs, fixtures and commits. Prefer local rules, bounded asynchronous provider calls, explicit cloud consent. Add tests for each change, report actual commands/results and untested platforms; attach screenshots for UI changes. Update roadmap and design docs when decisions change. Do not claim compilation or tests that were not run.
